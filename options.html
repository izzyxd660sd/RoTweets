Game-aware X feeds for Roblox. Version 1.1.1

Automatic game detection is enabled

RoTweet matches the Roblox game ID in the page URL to a built-in account preset. You don't need to configure anything for listed games. These are suggested game/developer accounts, not a guarantee of X verification. A custom handle below overrides a preset.

Default fallback account

The game-specific preset always takes priority unless you create a custom mapping for that game's ID.

About the feed

The extension uses an unofficial public profile reader and RSS mirrors. Providers can change or go offline; if that happens, the sidebar still links to the account on X. It does not inject X's blocked widgets.js script into Roblox.
